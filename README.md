# اسم فامیل v4.5

## دیپلوی

### فرانت (Vercel)
این فایل‌ها را در root پروژه بگذار:
- `index.html`
- `sw.js`
- `manifest.webmanifest`

### سرور (Render)
- `index.js` (یا `server.js`)
- `package.json`
سپس `npm install && npm start`
