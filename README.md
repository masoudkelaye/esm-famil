# 🎮 اسم فامیل آنلاین - راهنمای کامل نصب و استفاده

---

## 📱 دو فایل داری:

| فایل | کاربرد |
|------|---------|
| `index.html` | بازی کامل (آفلاین + آنلاین) |
| `server.js` | سرور آنلاین (برای بازی از راه دور) |

---

## 🚀 روش ۱: بازی آفلاین (فوری، بدون سرور)

### روی گوشی (آیفون یا اندروید):
1. فایل `index.html` رو بفرست رو گوشیت
2. با مرورگر باز کن (Safari / Chrome)
3. دکمه **📱 آفلاین** رو بزن
4. بازی شروع می‌شه!

### چند نفره روی یک گوشی:
1. اسم بازیکن‌ها رو وارد کن
2. دسته‌بندی‌ها رو انتخاب کن
3. هر بازیکن نوبتی جواب می‌ده
4. گوشی رو بده به نفر بعدی

### نصب مثل اپ واقعی:
**آیفون (Safari):**
- دکمه Share (⬆️) → Add to Home Screen

**اندروید (Chrome):**
- منو (⋮) → Install App / Add to Home Screen

---

## 🌐 روش ۲: بازی آنلاین (از راه دور)

### مرحله ۱: سرور رو رایگان دیپلوی کن

#### گزینه A: Glitch.com (ساده‌ترین)
1. برو به [glitch.com](https://glitch.com)
2. **New Project** → **glitch-hello-node**
3. محتوای `server.js` رو کپی کن
4. محتوای `package.json` رو کپی کن
5. آدرس پروژه‌ات مثل `https://esm-famil.glitch.me` می‌شه

#### گزینه B: Render.com
1. برو به [render.com](https://render.com)
2. **New → Web Service**
3. کد `server.js` و `package.json` رو آپلود کن
4. آدرس مثل `https://esm-famil.onrender.com`

### مرحله ۲: آدرس سرور رو توی بازی بذار
1. فایل `index.html` رو باز کن
2. خط ۲۸۰ رو پیدا کن:
   ```javascript
   let SERVER_URL = 'https://esm-famil-server.onrender.com';
   ```
3. آدرس سرور خودت رو بذار

### مرحله ۳: بازی رو روی اینترنت بذار

#### گزینه A: Netlify (ساده‌ترین)
1. برو به [netlify.com/drop](https://app.netlify.com/drop)
2. فایل `index.html` رو بکش بنداز
3. آدرس مثل `https://esm-famil.netlify.app` می‌شه

#### گزینه B: GitHub Pages
1. یه ریپو روی GitHub بساز
2. فایل `index.html` رو آپلود کن
3. Settings → Pages → Deploy

### مرحله ۴: بازی کن!
1. آدرس بازی رو باز کن
2. **🌐 آنلاین** رو بزن
3. **ساخت اتاق** بزن ← یه کد ۶ رقمی می‌گیری
4. کد رو بفرست برای دوستات
5. اونا کد رو وارد می‌کنن و بازی شروع می‌شه!

## 🎮 نحوه بازی آنلاین

### میزبان (Host):
1. اسمت رو بنویس
2. **🌐 آنلاین** بزن
3. تنظیمات بازی رو انجام بده
4. **شروع بازی** بزن
5. کد ۶ رقمی رو کپی کن و بفرست
6. وقتی همه اومدن، **شروع بازی** بزن

### بازیکن:
1. اسمت رو بنویس
2. کد ۶ رقمی رو وارد کن
3. **🚪 ورود** بزن
4. منتظر شروع بازی باش
5. جواب‌هاتو بنویس و ثبت کن
6. نتایج رو ببین!

## 🐛 مشکل داشتی؟

1. **سرور وصل نمی‌شه:** آدرس سرور رو توی `index.html` چک کن
2. **اتاق ساخته نمی‌شه:** کنسول مرورگر (F12) رو ببین
3. **بازیکن‌ها همدیگه رو نمی‌بینن:** مطمئن شو همه یه آدرس سرور دارن
